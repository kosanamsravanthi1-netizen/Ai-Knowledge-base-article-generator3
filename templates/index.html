RAG Architecture & System Overview

This application is a complete production-style college project demonstrating Retrieval-Augmented Generation (RAG).

  • Knowledge Base: Official Python 3.12 and Django 5.0 Documentation.
  • Vector Store: FAISS (Facebook AI Similarity Search) FlatIP Index with L2 normalized cosine similarity.
  • Embeddings: SentenceTransformers (all-MiniLM-L6-v2).
  • LLM Provider: Configurable Groq API (llama-3.3-70b-versatile) with offline RAG fallback.
  • Backend: Django REST Framework & SQLite/PostgreSQL.
  • Frontend: HTML5, CSS3, Vanilla JS (No heavy SPA frameworks or Streamlit).
